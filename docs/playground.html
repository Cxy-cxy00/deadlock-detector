1 แนบไฟล์หรือวางโค้ด

เลือกตัวอย่าง หรือวางโค้ด C ของคุณเองลงไปก็ได้

ลากไฟล์ .c จาก File Explorer มาวางบนช่องโค้ดด้านบนก็ได้

โค้ดถูก compile ด้วย gcc -std=c11 -Wall -Wextra -g -O0 -pthread แล้วรันในโฟลเดอร์ชั่วคราว เสร็จแล้วลบทิ้งอัตโนมัติ · กด Ctrl+Enter ในช่องโค้ดเพื่อรันผ่านเครื่องมือได้เลย
อยากรู้ว่าเครื่องมือดักฟังก์ชันและหา cycle ได้ยังไง ดูที่ ภาพรวมโปรเจ็ค

2 ผลลัพธ์

3 ข้อจำกัดที่รู้อยู่

เรื่องรายละเอียด
NORMAL mutex เท่านั้นinterpose แค่ pthread_mutex_lock / trylock / unlock · ไม่รองรับ condvar, timedlock, rwlock, semaphore, process-shared mutex
โปรแกรมที่ใช้ condvarเตือนเรื่องเจ้าของ mutex ไม่ตรงครั้งเดียว และอาจตรวจไม่เจอ deadlock ที่ผ่าน mutex ตัวนั้น (ไม่รายงานปลอม)
ต้อง dynamic linkstatic binary ไม่มีรายงานเลย เพราะ LD_PRELOAD ไม่มีผล
หลาย cycle พร้อมกันstderr ดิบมีครบทุกวง (สูงสุด 16 ต่อรอบ) แต่หน้านี้วาดแค่วงสุดท้าย
detection ไม่ใช่ preventionบอกว่าค้างที่ไหน ไม่ได้ทำให้ไม่ค้าง · ส่วนที่เตือนก่อนค้างมีแค่ [LOCK ORDER INVERSION] (อยู่ใน stderr ดิบ หน้านี้ไม่วาดเป็นภาพ)
lock-order inversionเฉพาะคู่ 2 mutex (ถือ A ขอ B สวนกับ ถือ B ขอ A) · วงลำดับ 3 ตัวขึ้นไปไม่เตือนล่วงหน้า · ไม่นับ trylock · โปรแกรมที่ใช้ condvar อาจได้คำเตือนผิด
ชี้บรรทัดต้องมี -g + PIEไม่มี debug info หรือเป็น non-PIE ก็ยังบอกได้ว่าใครค้างกับใคร แต่แสดงเป็น pc ดิบ
ไม่รองรับ recursive mutexthread เดิมล็อกตัวเดิมซ้ำจะนับเป็นครั้งเดียว
timeline ทีละขั้นเก็บเหตุการณ์ lock ได้ 5,000 ตัวแรก โปรแกรมที่ล็อกถี่กว่านั้นจะเห็นแค่ช่วงต้น (รอบตรวจของ detector ยังครบทุกรอบ)
Linux เท่านั้นLD_PRELOAD เป็นกลไกของ glibc dynamic linker
