make: Nothing to be done for 'all'.

==================================================================
  1) รันโปรแกรมโอนเงินธรรมดา
==================================================================

   $ ./build/bank

bank: โอนเงินสองทิศทางพร้อมกัน
      เงียบไปเกิน 1 วินาที = deadlock แล้ว (Ctrl-C เพื่อออก)

[t2] lock bob
[t1] lock alice
[t1] lock bob ...
[t2] lock alice ...

   ^ ค้างนิ่งจนถูกตัดที่ 3 วินาที
     ไม่ crash ไม่มี error message ไม่มี stack trace  CPU 0%
     นี่คือทั้งหมดที่ deadlock บอกเรา
   [ผ่าน]     ค้างจนหมดเวลา (exit 124)

==================================================================
  2) คำสั่งเดิมเป๊ะ แค่เติม LD_PRELOAD ข้างหน้า
==================================================================

   $ LD_PRELOAD=./build/nope.so ./build/bank

ERROR: ld.so: object './build/nope.so' from LD_PRELOAD cannot be preloaded (cannot open shared object file): ignored.
bank: โอนเงินสองทิศทางพร้อมกัน
      เงียบไปเกิน 1 วินาที = deadlock แล้ว (Ctrl-C เพื่อออก)

[t1] lock alice
[t2] lock bob
[t2] lock alice ...
[t1] lock bob ...

   ^ บอกครบ: thread ไหนถืออะไร รออะไร และบรรทัดไหนในซอร์ส

   เทียบกับซอร์สจริง:
     15: * barrier ของ glibc ไม่ได้เรียก pthread_mutex_lock ข้างใน (ใช้ futex ของมันเอง)
     65:    pthread_mutex_lock(&alice.lock);      /* <-- รายงานต้องชี้บรรทัดนี้เป็น "holds" */
     70:    pthread_mutex_lock(&bob.lock);        /* <-- ค้างตรงนี้ รายงานชี้เป็น "waiting" */
     89:    pthread_mutex_lock(&bob.lock);         /* <-- "holds" ของ t2 */
     94:    pthread_mutex_lock(&alice.lock);       /* <-- "waiting" ของ t2 ค้างตรงนี้ */
     119:    /* ไม่เคยคืนค่า — ทั้งสอง thread ค้างอยู่ใน pthread_mutex_lock */
   [ผ่าน]     ยังค้างอยู่ (exit 124) — เครื่องมือตรวจ ไม่ได้แก้
   [ไม่ผ่าน]  stderr ไม่มี [DEADLOCK DETECTED] — libdetect.so ไม่ได้ทำงาน

==================================================================
  3) export wait-for graph เป็นภาพ
==================================================================

   $ DD_DOT_OUT=cycle.dot LD_PRELOAD=./build/nope.so ./build/bank

   [ไม่ผ่าน]  ไม่ได้ไฟล์ cycle.dot หรือไฟล์ว่าง

   วงรี = thread  สี่เหลี่ยม = mutex
   T -> M คือกำลังขอ (แดง)   M -> T คือถูกถืออยู่
   ลูกศรวนครบรอบ = circular wait  ตรงกับ resource allocation graph ในสไลด์

==================================================================
  4) เวอร์ชันที่แก้แล้ว — ล็อกตามลำดับสากล
==================================================================

   $ LD_PRELOAD=./build/nope.so ./build/no_deadlock

ERROR: ld.so: object './build/nope.so' from LD_PRELOAD cannot be preloaded (cannot open shared object file): ignored.
no_deadlock: โค้ดเดียวกับ bank.c แต่ล็อกตามลำดับสากล
             ต้องจบเองภายใน ~1 วินาที และเครื่องมือต้องไม่รายงานอะไร

[t2] โอน bob -> alice
[t1] โอน alice -> bob
[t2] done
[t1] done

ยอดคงเหลือ: alice=1100 bob=900 (รวม 2000)
PASS: จบเองไม่ค้าง และยอดรวมถูกต้อง

   ^ บัญชีเดียวกัน โอนสวนทางกันเหมือนกัน
     ต่างแค่ทุก thread ล็อกตามลำดับสากลเดียวกัน
   [ผ่าน]     จบเองไม่ค้าง (exit 0)
   [ผ่าน]     ไม่มี [DEADLOCK DETECTED] (ไม่เตือนผิด)
