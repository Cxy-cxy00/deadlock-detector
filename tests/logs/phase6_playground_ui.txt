## บั๊กที่เจอระหว่างทดสอบ และแก้แล้ว
- อีก thread แทรกระหว่าง wait -> unwait -> acq ทำให้ "ล็อกได้ทันที" กลายเป็น "ขอ ... / ได้แล้ว (หลังจากรอ)"
  -> รวมขั้นโดยดูเหตุการณ์ถัดไปของ thread เดียวกัน ไม่ใช่เหตุการณ์ถัดไปทั้งไฟล์
- ลูกศร T1 → T2 กับ T2 → T1 ทับเป็นเส้นเดียว -> ลูกศรไปทางซ้ายยกสูงกว่า
- เส้น "ถืออยู่" กับ "กำลังขอ" ของคู่เดียวกัน (self-deadlock) ทับกัน -> โค้งคนละฝั่ง
